# ADR：架构决策记录

本目录存放架构决策记录（Architecture Decision Record）。

## 什么决策值得写一条

三条件全部满足才写，缺一不写：

1. **难逆**：改主意的代价可观（牵动数据布局、公共接口、目录结构）
2. **无上下文会困惑**：未来的读者会问「为什么当时这么选」
3. **真实权衡**：当时确实有几个像样的备选，是权衡后选的

## 写法

- 一条决策一个文件，编号递增：`0001-短横线-标题.md`
- 内容四段：**背景**（问题是什么）、**备选**（当时有哪些选项）、**决策**（选了哪个）、**理由**（为什么它是赢的那个）
- 只记录决策本身；术语见根目录 `GLOSSARY.md`
