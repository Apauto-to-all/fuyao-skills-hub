# 分诊标签

技能用五个固定的分诊角色说话；本文件把角色映射到本仓库 issue 跟踪器里实际使用的标签字符串。

| 技能里的角色标签 | 本仓库实际标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待维护者评估（未诊断） |
| `needs-info` | `needs-info` | 等报告人补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给 agent 实施 |
| `ready-for-human` | `ready-for-human` | 需要人来实施 |
| `wontfix` | `wontfix` | 不处理 |

技能提到某个角色时（例如“打上可交给 agent 实施的分诊标签”），使用右列对应的标签字符串。要换词只改右列，技能侧用语不变。
